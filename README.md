## 실행
빌드 과정이 없는 정적 사이트입니다. 저장소 루트에서:

```bash
python3 -m http.server 8000   # → http://localhost:8000/ (ColorBook은 /color/)
```
`index.html`을 브라우저로 바로 열어도 대부분 동작하지만, 작품 이미지의 픽셀을 읽는 시뮬레이터와 책 검색은 서버로 열어야 합니다. KaTeX와 글꼴은 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 구조

```
index.html, credits.html     서가 첫 화면, 이미지 크레딧
shared/css/style.css         공통 스타일(라이트/다크 토큰). 예시 그림의 색은 테마와 상관없이 고정
shared/js/common.js          공통 UI, 전역 AB: 레이아웃·검색·테마·퀴즈, 캔버스·차트·끌기, 흑백 보기·전/후 비교·색 견본
shared/js/art.js             공통 계산 엔진, 전역 ART: 색 변환(sRGB·XYZ·Lab·OKLCH·HSL), ΔE2000, WCAG·APCA,
                             분광 모형, 쿠벨카–뭉크 물감 혼합, 색각이상(Machado 2009), 색순응, 배색, 팔레트, 투시·그림자
shared/js/shelf.js, covers.js 서가 목록과 표지 그림
shared/img/                  공공 도메인 작품 이미지(WebP) + credits.json
color/                       ColorBook: book.js(장 목록), book.json, index.html, chapters/*.html
tools/head.py                장 <head>·사이트맵·JSON-LD·크레딧 생성기
tools/check.py               페이지 점검기(콘솔 오류, 가로 넘침, 조작 중 예외, 다크 모드 예시 색 불변)
```

집필 규칙은 [CONTRIBUTING.md](CONTRIBUTING.md)를 보세요. 레이아웃과 시뮬레이터 헬퍼는 같은 시리즈의 [InsureBook](https://github.com/geniuskey/insurebook)에서 가져왔습니다.

## 점검

```bash
node tools/test-art.cjs            # 엔진 검산
pip install playwright             # 처음 한 번
python3 tools/check.py             # 서가 전체(특정 장: python3 tools/check.py color/overview)
npm ci && npm run build            # 배포물(.book-dist/) 생성과 canonical·beacon 검사
```

## 배포 (GitHub Pages)
`CNAME`에 `art.euiyun.com`이 들어 있습니다. `main` 브랜치에 푸시하면 GitHub Actions가 `@euiyun/book`으로 `.book-dist/`를 만들어 배포합니다(저장소 Pages 설정의 소스를 GitHub Actions로 둡니다). 서가 전체가 한 번에 배포되며, 책은 하위 경로(`/color/`)로 나뉩니다.

## 용어집과 본문 뜻풀이

각 책의 용어 정의는 `<책 폴더>/glossary-data.js`의 `window.BOOK_GLOSSARY`에 저장합니다. 용어집과 본문 뜻풀이가 같은 데이터를 사용하며, 본문에서 용어에 마우스를 올리거나 키보드로 포커스하거나 모바일에서 탭하면 정의를 확인할 수 있습니다. 공통 동작과 스타일은 `shared/js/glossary-tooltips.js`, `shared/css/glossary-tooltips.css`입니다. 데이터 형식은 시리즈 공통 v1이며, 각 항목은 `ko`(이름), `en`(영문명), `abbr`(약어), `def`(정의), `chapters`(관련 장 목록)를 갖습니다. 이름이 반복되면 한 번만 표시하고, 묶음 항목은 가리킨 이름을 제목에 표시하며 구분에 필요한 비교 설명을 함께 제공합니다.
